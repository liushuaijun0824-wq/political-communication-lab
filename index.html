Research frame

A message can be AI-mediated without being false. Attribution stays visible when production disclosure and human accountability enter the audience judgment.

Construct: speaker traceability · Unit: political message · Outcomes: credibility, trust, legitimacy

Research method

Data preparation, analysis choices, statistical tests, and exports stay in a sequence a reviewer can follow.

The workbench does not call a language model. It demonstrates a review record around model-assisted labels.

  • The model proposes.The researcher rules.
  • Missing rows are reported.They are not quietly filled.
  • Every result is exportable.Every method can be rerun.

Research boundaries

Statistics can summarize a dataset. They cannot choose the construct, repair a weak design, or turn an assumption into evidence.

Questions

The workbench is intentionally narrow. These are the boundaries that matter most when a result starts to look persuasive.

Data privacy in the browser

CSV parsing and every calculation run in this tab. There is no upload, server database, or analytics call.

Research coding decisions

The tool compares model labels with reviewed labels and reports agreement. It does not decide which code is substantively correct.

Sample size in every test

Complete-case exclusion can change the analyzed sample. Reporting n keeps that change visible.
