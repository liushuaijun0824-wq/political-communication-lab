# Data-use note

This study uses publicly accessible NPR section pages. Each coded item retains its public URL, headline/snippet excerpt, source page, and fetch timestamp.

- Use: private/noncommercial methods demonstration and application portfolio.
- Scope: short excerpts (headlines and snippets) are used with source links for audit and coding transparency.
- Raw HTML snapshots: included for internal audit only; they should not be republished as a content product.
- Access: only public pages returning HTTP 200 were used. No login, paywall, bot protection, or access control was bypassed.
- Attribution: NPR is the source of the listed headlines/snippets; this study is not affiliated with or endorsed by NPR.
